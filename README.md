# HYDROGEN SPECTRUM V9.7 · QUANTUM LAB

수소의 대표 방출선 6종을 수집하는 1–4인 양자 카드 웹게임입니다. V8의 79장 덱과 V7 규칙을 유지하고 화면, 인터랙션, 애니메이션, 사운드와 접근성 설정을 개선했습니다.

## 바로 실행하기

1. Node.js 22.13 이상을 설치합니다.
2. 압축을 풀고 `hydrogen-spectrum-v9` 폴더에서 `npm run local`을 실행합니다.
3. `http://localhost:8787`에 접속합니다. Windows에서는 `START_WINDOWS.bat`을 사용할 수 있습니다.
4. 같은 Wi-Fi의 다른 기기에서는 `http://PC내부IP:8787`에 접속합니다. 방화벽에서 해당 연결을 허용해야 할 수 있습니다.

로컬 실행에는 추가 패키지 설치가 필요하지 않습니다. 서버가 종료되면 로컬 게임방은 사라집니다. 개인 연습 및 AI는 브라우저 안에서 실행됩니다. 온라인 방은 방 코드와 비밀 참가 토큰으로 접근합니다.

## V9.7 양수 에너지 준위와 움직이는 분광기

- 모든 참가자는 n = 1, 1 EU에서 시작합니다. n = 2–6은 14, 18, 19, 20, 21 EU입니다. 게임판, 카드 도감, 학습 힌트, AI와 서버는 같은 여섯 준위를 사용합니다. Hα의 전이는 18 → 14 EU이며 방출 카드 값은 −4입니다.
- 이전 버전으로 연 방도 재접속할 수 있습니다. 서버가 기존 전자 위치와 전이 기록을 새 눈금으로 한 번 변환하고 카드, 빛 토큰, 차례와 마감 시각을 이어받습니다.
- 첫 화면의 방전관과 분광기는 같은 카메라 움직임을 따릅니다. 네 가시 방출선(656, 486, 434, 410 nm)은 N-SF11 유리의 굴절률과 스넬 법칙으로 두 면을 추적한 광로 모형입니다. 방전관과 광선의 밝기는 함께 변합니다. 배경 빛결 또는 전체 애니메이션을 끄면 정지된 장면이 표시됩니다.

## V9.6 게임 모드와 사용 설명서

- 메인 화면의 닉네임·게임 모드·최대 인원 아래에서 선택한 모드의 목표와 시간을 읽을 수 있습니다. 모드를 바꾸면 안내도 바뀝니다. **게임 규칙 → 게임 모드**에서 네 가지 규칙을 비교할 수 있습니다.
- **일반**은 서로 다른 빛 6종, **스피드**는 원하는 빛 3종을 먼저 모으면 승리합니다. **5분 제한**은 6종을 먼저 모으면 즉시 승리하고, 5분이 지나면 현재 보유한 빛의 종류 수로 순위를 정합니다. 동점자는 공동 승리합니다. **학습**은 6종이 목표이며 숫자 카드에 현재 에너지와 계산 결과가 표시됩니다. 모든 모드에서 한 차례는 10초입니다.
- **차례 진행**에서 뽑기·전이·수집 순서와 카드 구성을, **방출선**에서 여섯 파장과 대응 전이를 확인할 수 있습니다. 어느 탭에서든 **카드 도감**을 눌러 카드 22종의 그림과 사용법을 넘겨 볼 수 있습니다.
- AI는 제거할 수 있는 토큰이 특정 파장의 마지막 하나뿐이면 다른 카드를 사용하거나 차례를 넘깁니다. 사람이 빛 제거 카드를 사용할 때는 도감에 적힌 제거 규칙을 따릅니다.
- 메인, 대기실, 네 게임 모드, 결과 화면에 서로 다른 음악이 흐릅니다. 플레이 중 승리까지 한 종류가 남거나 제한 경기의 마지막 30초에 들어가면 편곡이 달라집니다. 카드 개봉·페이지 넘김·빛의 흡수·방출·훔치기·제거에 각각 다른 소리와 시각 효과가 연결됩니다. 효과와 음량은 설정에서 조절할 수 있습니다.

## V9.5 빛 토큰 알림과 온라인 방 복귀

- 훔치기가 성공하면 토큰이 상대에게 이동하고, 제거가 성공하면 그 자리에서 파편으로 흩어집니다. 빛을 잃은 참가자에게는 ‘내 빛을 빼앗겼어요’ 또는 ‘내 빛이 제거됐어요’가 표시됩니다. 두 알림 모두 누가 누구의 어느 파장을 바꿨는지 표시하고 게임 기록에 남습니다. 훔치기에는 올라가는 차임, 제거에는 짧은 충격음과 파편음을 사용합니다. 효과음과 모션은 사용자 설정을 따릅니다.
- 게임 상단의 모드 옆에 6자리 방 코드가 보입니다. 누르면 6자리 코드가 복사됩니다. 참가자는 메인 화면에서 **코드로 참가**를 눌러 기존 자리에 돌아갈 수 있습니다. 처음 참가했던 기기의 같은 브라우저와 프로필을 사용합니다.
- **방 나가기**를 누르면 즉시 남은 인원 기준으로 차례가 돌아갑니다. 방장이 나가면 남은 참가자에게 방장 권한이 넘어갑니다. 탭 닫기나 통신 단절에는 약 20초의 재접속 유예가 있습니다.
- 혼자 남으면 경기가 종료되고 승패는 기록하지 않습니다. 복귀 가능 시각이 화면에 표시됩니다. **10분 안에 기존 참가자가 돌아와 두 명 이상이 되면** 모은 빛·에너지와 남은 시간으로 같은 판을 이어갑니다. 나간 사람이 진행하던 차례는 넘기고, 남아 있는 참가자가 이미 뽑은 카드는 복귀 시에도 유지합니다. 목표를 달성하거나 제한 시간이 끝난 경기는 최종 결과로 기록됩니다.

## V9.4 반응형 스펙트럼 연주판

- 여섯 건반을 누르면 선택한 선의 이름, 파장, 가시광선 여부와 전체 파형이 함께 표시됩니다. 같은 가로 구간을 그려 UV 122 nm에서는 마루가 촘촘하고 IR 1094 nm에서는 마루 사이가 넓게 보입니다. 각 선에 배정된 음높이와 색은 체험용입니다.
- 건반은 연주판의 실제 너비에 맞춰 재배치됩니다. 작은 휴대전화에서는 세 개씩 두 줄로 나뉘고 그 아래에 표시창이 놓입니다. 넓은 화면에서는 여섯 건반이 한 줄로 모이고 데스크톱에서는 표시창도 옆에 놓입니다. 보고 있는 파형은 화면을 돌려도 선택과 표시 위치가 유지됩니다.
- 화면 아래쪽에서 건반을 눌러 결과가 가려지면 표시창까지 자동으로 이동합니다. 반짝임은 누른 건반과 파형에 붙어 움직입니다. 사용자 설정에서 큰 글씨, 플레이 효과, 터치 효과를 조절할 수 있습니다.

## V9.3 카드 도감과 빛 연출

- **플레이 방법 → 카드 도감**에서 22종의 카드 원화와 사용법을 나란히 볼 수 있습니다. 화살표 버튼, 키보드 ←/→, 카드 그림을 좌우로 밀어 넘기는 방식이 모두 가능합니다. 그림을 누르면 확대됩니다.
- 숫자 카드는 흡수와 방출을 각각 한 줄에 모았습니다. ±1, 2, 3, 4, 5, 6, 7, 13 중 하나를 누르면 현재 게임 엔진이 허용하는 전이 전체와 해당 목표선을 표시합니다. 특수 카드 여섯 종류에는 사용 조건과 예시가 있습니다.
- 한글 제목에는 명조, 본문과 버튼에는 고딕, 계측값에는 고정 폭 숫자를 썼습니다. 글꼴 세 파일을 프로젝트에 포함했습니다. 기기에 저장한 설정에서 글자 크기를 한 단계 더 키울 수 있습니다.
- 관측소와 실제 플레이판에 청록·보라·금빛 물결이 움직입니다. 두 장을 뽑으면 앞면이 펼쳐지면서 한 장씩 테두리와 모서리가 빛나고 광택이 지나갑니다. 다시 뽑을 때는 새로 들어온 카드만 반짝입니다. 바로 카드를 선택할 수 있습니다.
- 화면이나 설명창을 누르면 터치 위치에 회절 고리와 작은 별빛이 퍼집니다. **사용자 설정 → 화면 연출**에서 전체 애니메이션, 배경 빛결, 플레이 효과, 터치·클릭 효과를 제어합니다. 음악·효과음과 음량은 별도로 저장됩니다.
- 게임 도중 도감·설정을 열어도 차례당 10초는 계속 흐릅니다. 시간이 끝나면 카드의 효과 선택창은 닫히고, 읽고 있던 도감이나 설정은 열린 상태로 유지됩니다.

## V9.2 분광기와 사운드

- 메인 화면의 **스펙트럼 연주**에서 UV부터 IR까지 여섯 키를 눌러 각 선의 파장, 게임용 표시색, 고유한 음색을 확인할 수 있습니다. UV와 IR을 선택하면 비가시광선 표시가 함께 나옵니다.
- 두 카드는 뒷면에서 앞면으로 펼쳐집니다. 카드 글자와 선택 영역은 즉시 활성화됩니다. 사용한 카드는 게임판에 작게 남아 어떤 카드가 전이를 일으켰는지 확인할 수 있습니다.
- 흡수에서는 빛이 전자 쪽으로 모이고, 방출에서는 전자에서 밖으로 나갑니다. 새 목표선을 얻으면 빛이 수집 위치에 도착하는 시점에 선 고유의 차임이 울립니다. 훔치기는 상대 기록에서 내 기록으로 이동하고, 제거는 해당 위치에서 빛이 흩어집니다.
- 게임이 끝나면 이번 판에 얻은 선을 파장 순서대로 분광판에 표시합니다. 파장 이름을 누르면 해당 전이를 볼 수 있습니다. 색과 소리, 신호창 파형은 게임용 표현입니다.
- 오리지널 BGM은 대기실의 건반과 패드(76 BPM), 플레이 중 베이스·타악기·현을 겹친 테마(104 BPM), 결과의 느린 종지(68 BPM)로 이어집니다. 한 참가자가 목표까지 한 선을 남기면 게임 테마에 타악기를 더합니다. 수집·전이 등 주요 소리를 재생할 때 음악을 잠시 낮춥니다.
- 모든 소리는 첫 터치나 키 입력 뒤 브라우저에서 합성합니다. 우측 상단 설정에서 음악, 효과음, 전체 음량과 모션 감소를 조절할 수 있습니다. 모션 감소를 켜면 이동과 입자 대신 관측 기록과 파장 표시로 결과를 확인합니다.
- 휴대폰에서는 시간 표시와 카드 선택판을 에너지 준위판 위에 배치했습니다. 이미지와 새 음원 합성 모듈도 오프라인 캐시에 포함됩니다.

## V9.1 차례당 10초 제한

- 차례가 시작되는 순간부터 **카드 뽑기·다시 뽑기·카드 사용·효과 선택을 합쳐 10초**입니다. 중간 조작으로 시간이 다시 늘어나지 않습니다.
- 10초가 되면 손의 모든 카드를 버림 더미로 보내고 다음 참가자의 차례로 자동 이동합니다. 카드를 아예 뽑지 않아도 넘어갑니다. 에너지·보유 토큰은 유지됩니다.
- 카드 사용을 일찍 마치거나 차례 종료를 누르면 즉시 다음 참가자에게 새 10초가 주어집니다. 4인에서는 순서대로 돌아가고, 1인 연습에서는 새 차례가 시작됩니다.
- 화면 상단과 카드 영역에 초 단위 카운트다운·진행 막대가 표시됩니다. 선택창에서도 시간이 보이며, 남은 3초에는 경고색과 짧은 효과음이 나옵니다.
- 효과 선택창을 열어 두어도 만료됩니다. 시간 초과 시 창이 닫히고 조작과 다시 뽑기 상태가 초기화됩니다.
- Cloudflare 직접 배포판은 **Durable Object의 영속 알람**으로 만료를 처리하고 WebSocket으로 전송합니다. 두 명 이상 참가 중일 때 서버에서 차례를 계속 진행합니다.
- 늦게 도착한 요청은 서버에서 만료를 먼저 검사하며, 새 차례에 예전 선택이 적용되지 않게 차례 식별자도 확인합니다.
- 기존 **5분 제한 모드**에서는 전체 게임 시간과 차례당 10초가 함께 적용되고, 전체 게임 종료가 우선합니다.
- 기존 저장 방은 업데이트 후 첫 서버 조회에서 현재 차례에 10초를 부여합니다. 연습·AI도 같은 10초 규칙을 적용합니다.
- 무활동 방 정리는 기존대로 유지됩니다. 자동 시간 초과만 반복된다고 방이 무기한 살아 있지 않습니다.
- 코드에서 시간을 변경하려면 `public/engine.js`의 `TURN_SECONDS=10`을 수정합니다. 다국어 규칙 설명의 10초 문구도 함께 수정해야 합니다.

## GitHub / Cloudflare 업데이트

이 전체 소스는 **KIMtg9616/HydrogenSpectrumGame**의 **hydrogen-spectrum-v9** Worker 업데이트용입니다.

1. ZIP을 풀고 안쪽 `hydrogen-spectrum-v9` 폴더를 엽니다.
2. 이 폴더 **안의** `public/`, `src/`, `scripts/`, `package.json`, `wrangler.jsonc` 등을 GitHub 저장소 루트의 같은 위치에 올려 커밋합니다. `public/fonts/`를 포함해 새 파일도 모두 올립니다.
3. 기존 Cloudflare Git 연결을 사용합니다. 프로젝트 루트는 `wrangler.jsonc`가 있는 위치이며, 빌드 명령은 비워 두고 배포 명령은 `npx wrangler deploy`입니다.
4. 프로덕션 배포 성공 후 기존 V9 주소를 새로고침합니다. 게임 상단 또는 맨 아래에 **V9.7**이 보입니다.

Worker 이름은 `wrangler.jsonc`에 `hydrogen-spectrum-v9`로 지정했습니다. 주요 화면 파일은 `public/app.js`, `public/field-guide.js`, `public/presentation.js`, `public/optics.css`입니다. 배경과 입력 연출은 `public/atmosphere.js`, 게임 이벤트와 조명은 `public/effects.js`에서 연결합니다.

- 카드 등장·호버·전이 미리보기·전자 이동·광자 비행·토큰 점등·승리 파티클·버튼 리플.
- 오리지널 Web Audio 앰비언트 BGM: 패드 화음, 베이스, 스테레오 아르페지오, 딜레이. 대기 화면과 게임의 템포가 달라집니다.
- 카드 뽑기·선택·흡수·방출·토큰 수집·공격·차례·승리를 구분하는 효과음. 전체·음악·효과음 음량을 따로 조절하며 화면을 떠나면 오디오를 일시 중지합니다.
- 우측 상단 설정에서 효과음, BGM, 음성 안내, 모션 감소, 큰 글자를 조절합니다. 설정은 기기에 저장됩니다.
- 한국어·영어·일본어·중국어 UI. 카드 그림 안의 문구는 한국어 원본이며 카드 아래에 선택 언어로 이름과 사용 가능 여부를 표시합니다.
- 키보드: D 뽑기, 1/2 카드, P 차례 종료, R 규칙. Tab/Enter 기본 조작, 대화상자 초점 관리, 상태 읽기 지원.
- 수집 슬롯을 누르면 목표 전이와 파장을 볼 수 있습니다. 규칙에서 기본 흐름·전이표·상세 규칙·과학 모형의 한계를 확인할 수 있습니다.
- PWA, 오프라인 연습·AI, 최근 30개 완료 게임의 기기 내 기록을 유지합니다.

브라우저 정책상 소리는 첫 클릭·터치·키보드 조작 후 시작됩니다. 음성·설치·전체화면은 브라우저별 지원 범위가 다릅니다.

## 게임 모드

- 싱글 연습, AI 1–3인 대전, 온라인 2–4인.
- 일반: 대표선 6종. 스피드: 3종. 5분 제한: 시간 내 최다 수집(동점 공동 승리), 6종 완성 시 즉시 종료. 학습: 6종과 계산 힌트.
- 방 최대 인원은 메인 하단 설정에서 변경합니다. 방을 만든 뒤 링크 또는 6자리 코드를 전달하고, 손님이 준비를 누른 다음 방장이 시작합니다.
- 게임 중 나갔다면 같은 브라우저에서 기존 방 코드를 입력하거나, 이전 방 복구 버튼이 보일 때 해당 버튼을 누릅니다. 차례당 10초를 넘기면 서버가 자동으로 차례를 넘깁니다.

## Cloudflare 직접 배포

이 배포 경로는 V8의 Workers + SQLite Durable Objects + WebSocket Hibernation 구조를 유지합니다.

```sh
npm install
npx wrangler login
npm run dev:cloudflare
npm run test:core
npm run deploy
```

기존 사이트를 업데이트할 때는 그 사이트의 Worker 이름을 사용합니다. 배포된 URL은 계정별로 다릅니다. 게임방은 최대 100개, 방당 최대 4명입니다. 무활동 방은 30분, 종료된 방은 10분 뒤 정리됩니다. 실제 계정 한도와 사용량에 따라 운영 가능량이 달라지며, 100방/400명 동시 부하 시험을 완료했다는 의미는 아닙니다.

## 함께 제공되는 웹 실행본

Sites 실행본은 D1에 방 상태를 저장하고 약 1.1초 간격 HTTP 조회로 동기화합니다. 조회할 때마다 참가 상태를 확인합니다. 약 20초 동안 접속 신호가 끊긴 자리는 다음 조회에서 자리 비움으로 처리합니다. Cloudflare 직접 배포판은 마지막 WebSocket 연결이 닫힌 뒤 같은 유예 시간을 적용합니다. 이 경로도 서버에서 차례·정원·카드 비공개를 검사하고, 버전 조건 갱신으로 동시 요청 충돌을 처리합니다. 별도 Cloudflare 배포용 WebSocket 코드는 `src/worker.js`에 그대로 포함됩니다.

제공된 실행 링크는 소유자 전용입니다. 다른 계정과 온라인 플레이하려면 별도 공개 Cloudflare 배포 또는 실행본의 방문 권한 설정이 필요합니다.

## 물리 모형 안내

게임 준위는 n=1부터 1, 14, 18, 19, 20, 21 EU입니다. 실제 수소의 속박 에너지는 전자와 양성자가 무한히 떨어져 정지한 상태를 0 eV로 잡으면 음수이며, 바닥상태가 약 −13.6 eV입니다. 게임 눈금은 실제 eV와 비례하지 않습니다. 준위판 간격과 궤도 장식은 실제 원자의 축척이나 전자 궤도를 의미하지 않습니다. UV 122nm 및 IR 1094nm는 비가시광선이며 표시색은 대체색입니다. 목표 외 하향 전이도 광자 방출로 표시하지만 새 토큰을 주지 않습니다. 실제 선택규칙과 자발 방출 수명은 생략했습니다. 빛 카드는 다른 수소 원자에서 검출한 빛의 기록, 공격 카드는 기록의 변화입니다.
