# HYDROGEN SPECTRUM V9.2 · QUANTUM LAB

수소의 대표 방출선 6종을 수집하는 1–4인 양자 카드 웹게임입니다. V8의 79장 덱과 V7 규칙을 유지하고 화면, 인터랙션, 애니메이션, 사운드와 접근성 설정을 개선했습니다.

## 바로 실행하기

1. Node.js 22.13 이상을 설치합니다.
2. 압축을 풀고 `hydrogen-spectrum-v9` 폴더에서 `npm run local`을 실행합니다.
3. `http://localhost:8787`에 접속합니다. Windows에서는 `START_WINDOWS.bat`을 사용할 수 있습니다.
4. 같은 Wi-Fi의 다른 기기에서는 `http://PC내부IP:8787`에 접속합니다. 방화벽에서 해당 연결을 허용해야 할 수 있습니다.

로컬 실행에는 추가 패키지 설치가 필요하지 않습니다. 서버가 종료되면 로컬 게임방은 사라집니다. 개인 연습 및 AI는 브라우저 안에서 실행됩니다. 온라인 방은 방 코드와 비밀 참가 토큰으로 접근합니다.

## V9.2 분광기와 사운드

- 메인 화면의 **스펙트럼 연주**에서 UV부터 IR까지 여섯 키를 눌러 각 선의 파장, 게임용 표시색, 고유한 음색을 확인할 수 있습니다. UV와 IR을 선택하면 비가시광선 표시가 함께 나옵니다.
- 두 카드는 뒷면에서 앞면으로 펼쳐집니다. 카드 글자와 선택 영역은 즉시 활성화됩니다. 사용한 카드는 게임판에 작게 남아 어떤 카드가 전이를 일으켰는지 확인할 수 있습니다.
- 흡수에서는 빛이 전자 쪽으로 모이고, 방출에서는 전자에서 밖으로 나갑니다. 새 목표선을 얻으면 빛이 수집 위치에 도착하는 시점에 선 고유의 차임이 울립니다. 훔치기는 상대 기록에서 내 기록으로 이동하고, 제거는 해당 위치에서 빛이 흩어집니다.
- 게임이 끝나면 이번 판에 얻은 선을 파장 순서대로 분광판에 표시합니다. 파장 이름을 누르면 해당 전이를 볼 수 있습니다. 색과 소리, 신호창 파형은 게임용 표현입니다.
- 오리지널 BGM은 대기실의 건반과 패드(76 BPM), 플레이 중 베이스·타악기·현을 겹친 테마(104 BPM), 결과의 느린 종지(68 BPM)로 이어집니다. 한 참가자가 목표까지 한 선을 남기면 게임 테마에 타악기를 더합니다. 수집·전이 등 주요 소리를 재생할 때 음악을 잠시 낮춥니다.
- 모든 소리는 첫 터치나 키 입력 뒤 브라우저에서 합성합니다. 우측 상단 설정에서 음악, 효과음, 전체 음량과 모션 감소를 조절할 수 있습니다. 모션 감소를 켜면 이동과 입자 대신 관측 기록과 파장 표시로 결과를 확인합니다.
- 휴대폰에서는 시간 표시와 카드 선택판을 에너지 준위판 위에 배치했습니다. 이미지와 새 음원 합성 모듈도 오프라인 캐시에 포함됩니다.

## V9.1 차례당 10초 제한

- 차례가 시작되는 순간부터 **카드 뽑기·다시 뽑기·카드 사용·효과 선택을 합쳐 10초**입니다. 중간 조작으로 시간이 다시 늘어나지 않습니다.
- 10초가 되면 손의 모든 카드를 버림 더미로 보내고 다음 참가자의 차례로 자동 이동합니다. 카드를 아예 뽑지 않아도 넘어갑니다. 에너지·보유 토큰은 유지됩니다.
- 카드 사용을 일찍 마치거나 차례 종료를 누르면 즉시 다음 참가자에게 새 10초가 주어집니다. 4인에서는 순서대로 돌아가고, 1인 연습에서는 새 차례가 시작됩니다.
- 화면 상단과 카드 영역에 초 단위 카운트다운·진행 막대가 표시됩니다. 선택창에서도 시간이 보이며, 남은 3초에는 경고색과 짧은 효과음이 나옵니다.
- 효과 선택창을 열어 두어도 만료됩니다. 시간 초과 시 창이 닫히고 조작과 다시 뽑기 상태가 초기화됩니다.
- Cloudflare 직접 배포판은 **Durable Object의 영속 알람**으로 만료를 처리하고 WebSocket으로 전송합니다. 방장·참가자의 브라우저가 닫혀도 서버의 차례 처리는 계속됩니다.
- 늦게 도착한 요청은 서버에서 만료를 먼저 검사하며, 새 차례에 예전 선택이 적용되지 않게 차례 식별자도 확인합니다.
- 기존 **5분 제한 모드**에서는 전체 게임 시간과 차례당 10초가 함께 적용되고, 전체 게임 종료가 우선합니다.
- 기존 저장 방은 업데이트 후 첫 서버 조회에서 현재 차례에 10초를 부여합니다. 연습·AI도 같은 10초 규칙을 적용합니다.
- 무활동 방 정리는 기존대로 유지됩니다. 자동 시간 초과만 반복된다고 방이 무기한 살아 있지 않습니다.
- 코드에서 시간을 변경하려면 `public/engine.js`의 `TURN_SECONDS=10`을 수정합니다. 다국어 규칙 설명의 10초 문구도 함께 수정해야 합니다.

## GitHub / Cloudflare 업데이트

압축을 풀고 **기존 저장소의 같은 위치에 프로젝트 내용물을 덮어쓴 뒤 Commit changes**를 누릅니다. Cloudflare의 새 프로덕션 배포가 성공한 뒤 기존 게임 주소를 새로고침하세요. 상단 또는 맨 아래 버전 표시가 **V9.2**이면 새 화면입니다. 예전 화면이 남으면 강력 새로고침(Ctrl+F5)을 사용합니다.

Cloudflare 설정: Build command는 비워 두고 Deploy command는 `npx wrangler deploy`를 사용합니다. 프로젝트 루트는 `package.json`과 `wrangler.jsonc`가 있는 위치입니다. 이번 업데이트는 기존 `wrangler.jsonc`의 Worker 이름 **hydrogen-spectrum-v8**을 유지하므로 기존 게임 주소를 그대로 사용합니다. 이미 Worker 이름을 바꿔서 사용 중이라면 본인의 이름을 유지하세요.

이번 연출의 주요 파일은 `public/app.js`, `public/presentation.js`, `public/effects.js`, `public/synth.js`, `public/audio.js`, `public/style.css`입니다. 표지 그림은 `public/art/observatory.webp`에 포함되어 있습니다.

## V9에서 달라진 점

- 남색·금색 실험실 테마, 별 배경, 원자 궤도 장식, 떠 있는 실제 카드, 여섯 빛의 네온 표현.
- 반응형 메인·대기실·게임판·카드 도감·규칙·설정창. 휴대폰에서는 에너지와 카드를 세로로 배치하고 수집한 빛을 기록보다 먼저 보여 줍니다.
- 카드 등장·호버·전이 미리보기·전자 이동·광자 비행·토큰 점등·승리 파티클·버튼 리플.
- 오리지널 Web Audio 앰비언트 BGM: 패드 화음, 베이스, 스테레오 아르페지오, 딜레이. 대기 화면과 게임의 템포가 달라집니다.
- 카드 뽑기·선택·흡수·방출·토큰 수집·공격·차례·승리를 구분하는 효과음. 전체·음악·효과음 음량을 따로 조절하며 화면을 떠나면 오디오를 일시 중지합니다.
- 우측 상단 설정에서 효과음, BGM, 음성 안내, 모션 감소, 큰 글자를 조절합니다. 설정은 기기에 저장됩니다.
- 한국어·영어·일본어·중국어 UI. 카드 그림 안의 문구는 한국어 원본이며 카드 아래에 선택 언어로 이름과 사용 가능 여부를 표시합니다.
- 키보드: D 뽑기, 1/2 카드, P 차례 종료, R 규칙. Tab/Enter 기본 조작, 대화상자 초점 관리, 상태 읽기 지원.
- 수집 슬롯을 누르면 목표 전이와 파장을 볼 수 있습니다. 규칙에서 기본 흐름·전이표·상세 규칙·과학 모형의 한계를 확인할 수 있습니다.
- PWA, 오프라인 연습·AI, 최근 30개 완료 게임의 기기 내 기록을 유지합니다.

브라우저 정책상 소리는 첫 클릭·터치·키보드 조작 후 시작됩니다. 음성·설치·전체화면은 브라우저별 지원 범위가 다릅니다.

## 게임 모드

- 싱글 연습, AI 1–3인 대전, 온라인 2–4인.
- 일반: 대표선 6종. 스피드: 3종. 5분 제한: 시간 내 최다 수집(동점 공동 승리), 6종 완성 시 즉시 종료. 학습: 6종과 계산 힌트.
- 방 최대 인원은 메인 하단 설정에서 변경합니다. 방을 만든 뒤 링크 또는 6자리 코드를 전달하고, 손님이 준비를 누른 다음 방장이 시작합니다.
- 게임 중 온라인 방에서 나가면 해당 방을 메인 하단 재접속 버튼으로 복구할 수 있습니다. 차례당 10초를 넘기면 서버가 자동으로 차례를 넘깁니다.

## Cloudflare 직접 배포

이 배포 경로는 V8의 Workers + SQLite Durable Objects + WebSocket Hibernation 구조를 유지합니다.

```sh
npm install
npx wrangler login
npm run dev:cloudflare
npm run test:core
npm run deploy
```

기존 사이트를 업데이트할 때는 그 사이트의 Worker 이름을 사용합니다. 배포된 URL은 계정별로 다릅니다. 게임방은 최대 100개, 방당 최대 4명입니다. 무활동 30분/종료 후 10분이 지나면 정리됩니다. 실제 계정 한도와 사용량에 따라 운영 가능량이 달라지며, 100방/400명 동시 부하 시험을 완료했다는 의미는 아닙니다.

## 함께 제공되는 웹 실행본

Sites 실행본은 D1에 방 상태를 저장하고 약 1.1초 간격 HTTP 조회로 동기화합니다. 브라우저가 닫히면 참가 상태를 정확히 감지하지 않으므로 대기실에는 호스트/준비 상태를 표시합니다. 접속 인원은 방에 등록된 사람 수입니다. 이 경로도 서버에서 차례·정원·카드 비공개를 검사하고, 버전 조건 갱신으로 동시 요청 충돌을 처리합니다. 별도 Cloudflare 배포용 WebSocket 코드는 `src/worker.js`에 그대로 포함됩니다.

제공된 실행 링크는 소유자 전용입니다. 다른 계정과 온라인 플레이하려면 별도 공개 Cloudflare 배포 또는 실행본의 방문 권한 설정이 필요합니다.

## 물리 모형 안내

게임 에너지 0, 13, 17, 18, 19, 20은 실제 eV와 비례하지 않는 게임 단위입니다. 준위판 간격과 궤도 장식은 실제 원자의 축척이나 전자 궤도를 의미하지 않습니다. UV 122nm 및 IR 1094nm는 비가시광선이며 표시색은 대체색입니다. 목표 외 하향 전이도 광자 방출로 표시하지만 새 토큰을 주지 않습니다. 실제 선택규칙과 자발 방출 수명은 생략했습니다. 빛 카드는 다른 수소 원자에서 검출한 빛의 기록, 공격 카드는 기록의 변화입니다.

## 검증

- `npm run test:core`: 규칙 및 10초 제한/Cloudflare 알람 테스트 23개. 79장 구성, 6종 전이, 다시뽑기, 훔치기/제거, 일반/스피드/시간 종료, 카드 비공개, AI 4인 게임 30회 카드/토큰 보존.
- `npm test`: 위 테스트와 Sites 어댑터 테스트 4개, 카드 연출 회귀 테스트 4개(총 31개). Node.js 내장 SQLite를 사용하므로 Node.js 22.13 이상이 필요합니다. 4인 동시 참가, 마지막 자리 경쟁, 준비·차례 권한, 카드 비공개, 방 100개 제한, 만료, 외부 출처 변경 요청, 동시 시간 초과 요청의 중복 차례 이동 방지를 검사합니다. 추가로 알람 재시도, 카드 보존, 늦은 카드 사용 거부, 재추첨 시간 유지, 1인/4인 순서, 5분 모드 우선 종료, 기존 방의 시계 초기화를 검증합니다.
- 브라우저에서 카드 뽑기, 전이, 수집, 스피드 모드 종료까지 확인했습니다. 320·390·768픽셀 폭에서 4인 게임의 뽑기와 두 장 선택 화면을 검사했습니다.
- 브라우저의 OfflineAudioContext로 세 장면의 스테레오 출력, 합성 효과음과 음악을 동시에 재생한 샘플의 피크, 음소거, 여섯 선의 서로 다른 음높이를 검사했습니다.
- 휴대폰 실기기 음향 청취, 운영용 Cloudflare WebSocket 접속, PWA 설치 및 다수 동시 방 부하 시험은 별도 확인 대상입니다.
